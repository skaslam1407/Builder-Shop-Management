# User Guide (Initial Outline)

## First-time setup
1. Install the application.
2. Sign in with the initial administrator account created during secure setup.
3. Change the initial password.
4. Enter company details and GST configuration.
5. Configure invoice numbering and print preferences.
6. Add categories, units, and materials.
7. Add customers and suppliers.
8. Enter opening stock and balances through controlled opening entries.

## Daily billing workflow
1. Open Sales / New Invoice.
2. Select GST or non-GST invoice mode.
3. Select a customer or use the configured walk-in customer workflow.
4. Add materials and quantities.
5. Verify rates, discounts, tax, and total.
6. Save as draft or finalize.
7. Record full or partial payment.
8. Print or reprint the invoice.

## Purchase workflow
1. Create a purchase invoice.
2. Select supplier and enter supplier invoice details.
3. Add materials, quantities, rates, and tax details.
4. Review totals and finalize.
5. Record supplier payment if made.

## Reports
Use date filters to view sales, collections, outstanding balances, purchases, expenses, and stock reports. Export only when authorized.

## Backup
Create backups regularly and store a copy on a separate trusted storage device. Periodically test restore using a separate test copy.

This guide must be updated to match the final application UI and actual business workflow.
